Entry
CoBaLT.cpp
CoBaLT.cpp
Program entry point. Initialises all subsystems, loads assets, then runs the BeginDrawing/EndDrawing main loop until WindowShouldClose().
  • main(argc, argv)init → loop → destroy
calls init: Win::Init()gFont.Load()gSound.Load()gSettings.ReadSettings()gPalette.ReadPaletteFile()
each frame: ctrl.Update()f.RetokenizeDirtyLines()cm.DrawCursors()f.Draw()cnsl.Draw()fq.Draw()DrawInfo()
Init / Globals
Win
CBLT_Win.hpp / .cpp
Window lifecycle. Creates the raylib window, sets icon, target FPS, disables ESC exit key.
  • Win::Init()InitWindow, SetTargetFPS
  • Win::Destroy()CloseWindow
global: std::string Version
EditorSettings
CBLT_Settings.hpp / .cpp
Parses options/settings.cbltconf. Holds tab size, terminal strings, palette name, cursor symbol, and five AnimationProfile structs.
  • ReadSettings()reads %settings block
calls: ReadAnimationFile(path) for each ANIM_* option
global: gSettings
EditorFont
CBLT_Font.hpp / .cpp
Loads a TTF with an extended glyph set (ASCII + box-drawing + block elements). Builds an advanceMap for fast per-glyph width lookup. Four instances: gFont, gConsoleFont, gTopBarFont, gFileQueueFont.
  • Load(fontName)LoadFontEx, TEXTURE_FILTER_BILINEAR
  • Config()builds advanceMap[]
  • BuildGlyphSet()ASCII + U+2500–U+259F
  • Utf8ToCodepoints(str)UTF-8 → i32 codepoints
calls: LoadFonts(path) Parses the font names and sizes from options/font.cbltconf and loads them to the globals
globals: gFontgConsoleFontgTopBarFontgFileQueueFont
SoundSystem
CBLT_Sound.hpp / .cpp
Owns a fixed Sound[EDITOR_SOUNDS_COUNT] array. Plays with a random pitch variation (0.67–1.45×) to avoid monotony.
  • SoundSystem()InitAudioDevice()
  • Load(path)LoadSound for all 16 slots
  • Play(SoundClass)SetSoundPitch + PlaySound
  • ~SoundSystem()UnloadSound × 16, CloseAudioDevice
enum: SoundClass (INSERT, DELETE, NAV, RETURN, SPACE, console × 7, FQ × 2, EXIT)
global: gSound
Palette
CBLT_Palette.hpp / .cpp
Holds ~35 named Color fields. Reads a .pal file (key:[r,g,b] pairs inside %pal block). Falls back to hardcoded defaults.
  • ReadPaletteFile(path)parses %pal block → Color fields
helper: toCol(cblt_color) avoids WIN32 Color collision
global: gPalette
Animation
Animator
CBLT_Animation.hpp / .cpp
Each cursor and the console cursor owns an Animator. AnimationProfile (loaded from .cbltconf) selects ease type, speed, overshoot, stiffness, damping. Update() runs every frame.
  • MoveTo(x, y)starts Interpolator if position changed
  • Update()advances Interpolator, applies ease formula
  • Snap(x, y)instant reposition, no animation
  • SetProfile(profile*)points to gSettings AnimationProfile
  • IsMoving()delegates to Interpolator::IsActive()
  • ReadAnimationFile(path)parses .cbltconf → AnimationProfile
eases: NONELINEAREASE_INEASE_OUTELASTICBOUNCE
Interpolator
CBLT_Interpolator.hpp / .cpp
Low-level linear interpolator. Progress goes 0→1 at speedPerFrame. Animator owns one; it reads SourceX/Y and TargetX/Y to apply its own ease on top.
  • Start(fx,fy,tx,ty,speed)resets progress → 0, sets active
  • Update()progress += speed; returns {x,y}
  • Stop()active=false, progress=1
  • IsActive() / Progress()state queries
  • SourceX/Y(), TargetX/Y()read AnimationLine struct
Controller
Controller
CBLT_Controller.hpp / .cpp
Central input dispatch. Called once per frame via Update(). Owns Keyboard, FileQueue (Q), Console, and cwd string. Routes keys to the correct handler based on console open/closed state and cursor mode (INSERT / SELECT).
  • Update()modifiers → console or file input dispatch
  • HandleMovement(cursor, inConsole)arrow keys, word boundary jump
  • HandleSpecialMovement(cursor)Ctrl+← / → word jumps
  • HandleSpecials(cursor)Backspace, Enter, Tab, Escape
  • HandleInsert(cursor, keyQueue)typed chars, bracket pairing
  • HandleConsole()console char input, history nav
  • HandleShorcuts(cursor)Ctrl/Alt combos → save, nav, etc.
  • HandleSelectEntry/Exit(cursor)SELECT mode transitions
  • HandleSelectionSpecials(cursor)Backspace/Enter in SELECT
  • DeleteSelected(cursor)normalises selection, erases lines
  • GetKeyQueue()drains GetCharPressed() → vector<char>
  • GetIndentation(line)counts unmatched '{' for auto-indent
  • HandleMouseWheel/Click()scroll lines, click-to-position cursor
  • HandleConsoleMouseWheel/Click()CWD entry hover + click-to-NQ
  • InitCWD(path)sets cwd string from argv[1]
calls each frame: keyboard.UpdateModifiers()console.Update()console.Execute(Q,cwd) Q.Active().Auto()f.RetokenizeDirtyLines()gSound.Play()
Keyboard
CBLT_Keyboard.hpp / .cpp
Wraps raylib input. Tracks Ctrl/Shift/Alt modifier state. Constructs the tab-stop string from settings.
  • GetKey()GetCharPressed() → i32
  • UpdateModifiers()IsKeyDown for L-Ctrl, L-Shift, L-Alt
  • AssignTabSize(size*)rebuilds tab string (spaces)
  • CtrlActive/AltActive/ShiftActive()modifier queries
struct: Modifiers {ctrl, shift, alt}
Console
Console
CBLT_Console.hpp / .cpp
Right-side panel. Toggled via Ctrl+`. Holds a Directive (single-line File), CWD content list, its own CursorManager, Camera, and history list. Execute() parses the directive line and dispatches to ~40 commands.
  • Toggle()toggled = !toggled
  • Execute(Q, cwd)parse ':' or file-switch context, dispatch command
  • GetCWDContents(cwd)filesystem::directory_iterator → cwdContents[]
  • Draw(Q, rect)background, directive bar, scissor-clipped CWD list, hover rect
  • DrawMessage()DIRECTIVE_ERROR / INFO / GUIDE / FILE_MARKS overlays
  • DrawGuide()renders gGuideMessage when no file open
  • Autocomplete()prefix match on cwdContents for Tab completion
  • Move(offset)resize width, clamped to [20, 0.5×screenWidth]
  • Scroll(dy)clamps cameraOffset.y to content height
commands (subset): :w :wq :wqa :q :qa :qas:cd :up :o:g :gs :ge :gm :gml :mat :umat :uml :uma :im:f :c :r :m :d :pal :sh :h :i :e :we :msg :rst :set :log
owns: Directive directivevector<CWDContentToken> cwdContents CursorManager cursorCamera cameralist<string> directiveHistory
Directive
CBLT_Directive.hpp / .cpp
Thin wrapper around a File used as a single-line input buffer. Index 0 = the typed command. gGuideMessage is the help text rendered by DrawGuide().
  • Clear()GetCurrentLine(0).clear()
  • Becomes(src)clear + append — used by autocomplete and history
  • Draw(x, y)DrawTextEx with gConsoleFont
  • DirectiveFile()returns File& for cursor ops
global: std::string gGuideMessage (help text)
const: DIRECTIVE_FILE_LINE = 0
CWDContentToken
CBLT_CWDContentToken.hpp / .cpp
Simple value type produced by GetCWDContents(). Colour-codes dirs vs files. Consumed entirely by Console::Draw() and Console::Autocomplete().
  • CWDContentToken(clr, name, isDir)direct field init
fields: Color cstring nbool isDir
File Queue
FileQueue
CBLT_FileQueue.hpp / .cpp
Holds up to 32 File objects (MAX_FILE_Q_NODES). Tracks activeIndex. Renders the bottom file-tab bar with separators and camera offset for horizontal scrolling.
  • LoadFileToQueue(name, cwd)emplace_back + File::Load
  • CloseFile(idx)erase + clamp activeIndex
  • SetActiveNext/Prev()wraps around queue bounds
  • Active()loadedFiles[activeIndex] ref
  • Draw()renders tab bar with camOffset.x scroll
  • Scroll(dx)camOffset.x ± clamped to ±screenWidth
owns: vector<File>Camera camOffset camOffset
File
CBLT_File.hpp / .cpp
Core document abstraction. Stores lines[], token table, lexer states, dirty-line set, language, autocomplete, marks, cursors, camera, and offsets. All mutation goes through File methods to keep dirty-tracking consistent.
  • Load(fpath, cwd)ifstream → lines[], AssignExtension → Language, Tokenize(), LoadMarks()
  • Save()ofstream, writes lines joined by '\n', SaveMarks()
  • InsertChar(col, line, c)string::insert, InsertDirtyLine()
  • DeleteLine(line)erase lines/tokens/lineStates, InsertDirtyLine
  • CreateLine(line [,content])emplace + inherit LexerState
  • SplitLine(line, col)splits string, returns right fragment
  • PushBackLineFragment(src, dst)appends src line to dst (backspace at col 0)
  • Tokenize()full re-lex of all lines via LexLine()
  • InsertDirtyLine(line)adds to dirtyLines unordered_set
  • RetokenizeDirtyLines()re-lex from min dirty line, stabilise on state match
  • Draw(cursorX, cursorY, consoleOpen, cW)scissor-clipped token render, line numbers, marks, autocomplete popup
  • ClampCursor(cursor)clamps col/line to actual content bounds
  • AddMark/RemoveMark(line)vector<InfileMark> + ReIndex factory
  • SaveMarks() / LoadMarks()hex-encoded sidecar .marks file
  • Info()returns metadata string for :i directive
  • GetMarksAndNearbyLinesMessageString()context lines around each mark
owns: vector<string> linesvector<vector<Token>> tokens unordered_set<ui32> dirtyLinesvector<LexerState> lineStates Language langInfileAutocomplete autocomplete vector<InfileMark> marksCursorManager cursors Camera camOffset off
Language & Lex
Language
CBLT_Language.hpp / .cpp
Reads a .cbltconf lang file (60+ languages mapped in gLangFiles). Populates keyword sets, operator set, comment/string delimiters, macros, annotations, and language settings flags.
  • Language(FileExtension)looks up gLangFiles, calls ReadLangFile
  • ReadLangFile(fname)parses %keywords:, %operators:, %commentBlock:, %settings: sections
  • IsKeyword(string)checks all 6 keyword unordered_sets
  • IsOp(string)checks operators set
struct: LanguageKeywordsLanguageSettings global: gLangFiles (unordered_map<FileExtension, string>)
Lexer — LexLine()
CBLT_Lex.hpp / .cpp
Stateless function. Takes a line string + previous LexerState, produces a vector of Tokens, returns new state. Handles block comments across lines via LexerState::INBLOCK.
  • LexLine(s, line, state, lang, tokens)full single-line lex pass
order: INBLOCK cont.block comment openline commentmacro/annotationstringoperatorpunctuationidentifier/keywordnumbermisc fallthrough
enum: LexerState {NONE, INBLOCK, INCOMMENT, INMACRO, INANNOTATION, INSTRING}
Token
CBLT_Token.hpp / .cpp
POD-like: type, line, col, len. TokenColor() maps type → gPalette colour. GetCursorX() accumulates glyph advance widths up to a column for pixel-accurate rendering.
  • Token(tc, line, col, len)direct field init
  • TokenColor()switch(type) → gPalette.lex_*
  • GetCursorX(lineText, fontSize, column)UTF-8 codepoint advance sum
enum: TokenClass {ID, KEYWORD, NUM, STRING, COMMENT, OPERATOR, WHITESPACE, PUNCTUATION, MISC, UNKNOWN, FUNCTION}
Cursor System
CursorManager
CBLT_Cursor.hpp / .cpp
Holds vector<Cursor> activeCursors. Manages multi-cursor add/remove and pending requests (lead/trail/reset) resolved each frame via HandlePendingRequests().
  • AddCursorAt(col, line)emplace_back
  • RemoveCursorAt(col, line)find + erase
  • RemoveSecondaries()erase [1..end]
  • HandlePendingRequests(lineCount)processes requestReset, requestLead, requestTrail
  • DrawCursors(font, xOff, yOff, off)calls Cursor::Draw on each
  • Primary()activeCursors[0] ref
  • RequestReset/Lead/Trail()set boolean flags
Cursor
CBLT_Cursor.hpp / .cpp
Holds column, line, select start/end fields, mode (INSERT/SELECT), fragment string. Owns an Animator for smooth movement. Draw() uses BeginScissorMode to clip below the topbar.
  • SetAt(col, line, targetLine)clamps col, calls animator.MoveTo()
  • Up/Down/Left/Right(targetLine)delegates to SetAt
  • Draw(font, xOff, yOff, off)animator.Update(), DrawSelection if SELECT, draws symbol
  • DrawSelection(font, xOff, yOff, off)multi-line selection rects
  • GetCursorX(lineText, fontSize)UTF-8 glyph advance sum to column
  • AcquireFragment(col, line)walk left/right to word boundary → fragment
  • SetToWordBoundary(text, dir, lineCount)Ctrl+←/→ word jump logic
  • ClampToCamera(cam, line, off)adjusts off.x/y to keep cursor in view margin
  • StartSelection/StopSelection()captures start/final col+line
  • Classify(c)INWORD / WHITESPACE / SYMBOL
owns: Animator animatorCursorSymbol* cursorSymbol
InfileAutocomplete
CBLT_InfileAutocomplete.hpp / .cpp
Token-indexed suggestion engine. Maintains per-line token sets and a global set. Merges language keywords. Renders a scrollable popup box that flips above cursor if near screen bottom.
  • LoadTokens(fileTokens, fileText, lang)builds lineTokens[] + allTokens from full lex pass, merges lang keywords
  • UpdateLine(line, tokens, text)evicts old line tokens, inserts new ones
  • GetSuggestions(fragment)prefix scan over tokens vector (max 27 results)
  • DrawSuggestions(cursorX, cursorY)sliding window of 6, highlights current, flips if near bottom
  • Up/Down()navigate current index
  • Open/Close/Dismiss/Valid()state machine: open, dismissed, closed
  • GetCurrentSuggestion()returns suggestions[current]
state: open booldismissed bool — dismissed prevents reopen until Valid() called
InfileMark
CBLT_InfileMark.hpp / .cpp
A line bookmark with a sequential id. Persisted to a hex-encoded sidecar file under meta/marks/. Drawn as a coloured rect + id number on the right margin of the file view.
  • InfileMark(line)sets id=0, line=l
  • Draw(renderX, renderY, width)DrawRectangle + DrawTextEx id
  • ReIndex(i)called after any mark add/remove
  • Line() / Id()getters
persistence: MarkFileEncode(path) hex-encodes full path → sidecar filename
Camera + Offset
CBLT_Camera.hpp / .cpp
Axis-aligned 2D viewport. Each File and FileQueue has its own Camera. Console has one too. Offset (x,y) is the scroll position. ClampToCamera in Cursor adjusts Offset to keep cursor inside the margin.
  • Set(x, y, off)sets off.x/y directly
  • Move(dx, dy, off)off.x/y += delta
  • Contains(x, y, w, h)AABB check vs origin+width/height
  • SetOrigin/SetWidth/SetHeight()resize after window resize
  • MarginX/Y()scroll trigger zone (90px / 60px)
struct: Offset {f32 x, y}CameraOrigin {i32 x, y}
Platform Layer
Dialog
CBLT_Dialog.hpp
Native folder picker. Three separate TU implementations selected by preprocessor. Linux cascades: zenity → kdialog → yad → dialog → whiptail → xdg-open.
  • OpenFolderPicker()returns selected path string
  • RunCommand(cmd)popen (POSIX) / IFileDialog COM (Win32)
  • OpenFolderPickerPortal()Linux: xdg-desktop-portal variant
Win32: CoCreateInstance(CLSID_FileOpenDialog)FOS_PICKFOLDERSWideCharToMultiByte
global: gDialog
ShellBridge
CBLT_ShellBridge.hpp
Spawns a native terminal in the current cwd. POSIX forks and execlp with a bash --init-file command that sources .bashrc. Win32 builds a command string for cmd/powershell/wt and calls CreateProcessA.
  • Execute(cmd, cwd)spawn terminal; returns cwd string
POSIX: fork()chdir(cwd)execlp(term, "-e", "bash", "-c", cmd)
Win32: CreateProcessA()CREATE_NEW_CONSOLE
global: gShellBridge
Sys
CBLT_Sys.hpp / .cpp
Two thin free functions. ResourcePath reads CBLT_RESOURCES env var on Linux, returns "." on other platforms. WorkingDirectory returns argv[1] on Linux, getcwd on macOS, "C:/" on Win32.
  • Sys::ResourcePath()getenv("CBLT_RESOURCES") or "."
  • Sys::WorkingDirectory(argc, argv)argv[1] / getcwd / "C:/"
Util / Types
CBLT_Util.hpp
Typedefs under UT namespace. Error log (append to log/dir.log). Utility functions. FileMargins layout constants used by File::Draw and Cursor::ClampToCamera.
  • UE::Log(msg)gLogFile << "CBLT_LOG: " << msg
  • UE::Init()opens log/dir.log in append mode
  • UF::Trim(str)strips whitespace both ends
  • UF::TrimLeadingColon(str)strips ':' prefix from directive
  • UF::C(r,g,b)cblt_color constructor (avoids WIN32 collision)
  • UF::MarkFileEncode(path)hex-encodes path string → sidecar filename
macros: UT = Types UE = Err UF = Func UDef = Def
FileExtension
CBLT_FileExtension.hpp
Enum of 60+ extension types. AssignExtension() maps a file path's extension string to the enum value used to select a language conf.
  • AssignExtension(path)find_last_of('.'), string match → FileExtension enum
called by: File::Load() to pick Language
Render & Base
DrawInfo (TopBar)
CBLT_TopBar.hpp / .cpp
Free function called each frame from main loop. Draws the top status bar: col/line, line count, dirty state, cursor mode, filename, lang conf name, cursor fragment, CWD. Two vertical separators.
  • DrawInfo(cursor, lineCount, dirty, fname, cwd, conf)MeasureTextEx → positions, DrawTextEx × 8, DrawLine × 2
reads: gTopBarFontgPalettecursor.Col/Line/Fragment/GetMode()
CursorSymbol
CBLT_CursorSymbol.hpp
Enum controlling cursor glyph style. Stored in gSettings, pointed to by each Cursor. Cursor::Draw() switches on this to render underscore, box, hollow box, or line cursor.
  • NON_ASCII_UNDERSCORE1px rect at baseline
  • NON_ASCII_BOXfilled rect glyph-width × font-height
  • NON_ASCII_HOLLOW_BOXoutline rect
  • NON_ASCII_LINE1px wide vertical bar
